Furniture Planner — How to Run (Mac)
====================================

Requirements
------------
- Node.js and npm: https://nodejs.org/

Run the planner
---------------
1. Unzip or clone the FurnitureSearch project.
2. Open Terminal and change to the project folder:

   cd /path/to/FurnitureSearch

3. Start the local web server:

   npm start

4. The planner should open automatically. If it does not, visit:

   http://localhost:8080

The included furniture data loads automatically. You can also choose a different
CSV file from the planner.

When finished, return to Terminal and press Control+C to stop the server.
